# FinWise — финансовая грамотность в игре

Веб-демонстрация проекта FinWise: приложение, где дети и подростки Казахстана (10–20 лет) учатся обращаться с деньгами через мини-игры.

**Открыть сайт:** https://asanali703.github.io/finwise-web/

## Что внутри
- 6 мини-игр с уроками на 3 уровня (школьник, подросток, студент): бюджет, «нужно или хочу», мифы о деньгах, мошенники, сложный процент, первая работа и налоги
- Квесты дня, сундук, достижения, демо-лига
- Копилка с целями и калькулятор сложного процента
- Помощник по деньгам (поиск по готовым ответам, не ИИ)
- Биржа-тренажёр с вымышленными компаниями
- Раздел для родителей и форма отзывов тестеров

## Как устроено
Один файл `index.html` (HTML + CSS + JavaScript), без библиотек и сервера. Прогресс хранится только в браузере (localStorage).

Все суммы, компании, ставки и участники лиги — вымышленные или упрощённые, это учебный проект, а не финансовый совет.
